# Contributing to Rifare

The project is a planning starter. License and public contribution terms require the M00-G03 decision before external contributions are solicited. For authorized development, read `AGENTS.md` and follow one assigned packet with an isolated worktree and preserved regression contracts.

Run `python3 tools/verify.py`. Submit exact-candidate results, meaningful failure proof and independent reviews. Do not commit raw generated evidence or secrets. Change canonical planning JSON and regenerate cards rather than editing only generated views. No author self-acceptance or unapproved publication.
