# Use the assigned checkout

Inspect git status, branch and git worktree list. Resume the assigned primary or suitable existing checkout; create a linked checkout only for actual isolation. Preserve user changes, refs, configuration and evidence. Use one writer and isolated local resources for native tests. After terminal work preserve checkpoints and remove only clean inactive linked checkouts using normal git worktree remove. Follow the workspace lifecycle policy; do not stop unrelated processes or services.

Earlier workflow adaptation attribution remains in THIRD-PARTY-NOTICES.md.
