# Working on Rifare

Read README.md, docs/ARCHITECTURE.md and docs/DEVELOPMENT.md. Use one writer
per branch. Preserve user changes, ignored configuration, credentials and raw
evidence. Do not create additional checkouts without an actual isolation need.

Medusa/PostgreSQL is the only application runtime. Do not restore the retired
SQLite engine, parallel commerce servers, demo clients or bespoke planning/test
framework. The owner authorized their removal in ADR-0093 before complete
feature equivalence. Missing features belong in the Medusa application.

Use ordinary npm commands. Run `npm run check` after a coherent change; invoke the affected whole test file directly when a smaller check is appropriate. Run a build when build/source
loading changes. Run relevant native database verifiers for database/effect
changes. Do not start full historical campaigns or hash entire vendor trees for
routine edits. A focused check is not production acceptance.

Keep native ownership/currentness, exact payment equality, replay/refusal,
privacy and stale-worker guards intact. Authentication is not purchase authority.
Keep production and unqualified public effects held. Other workers own provider
infrastructure; do not change Supabase or ElevenID deployments here.

Obtain independent authority and regression review for meaningful boundary
changes. User-directed retirement is retired coverage, never a passing test.
No fabricated approval, legal clearance, connected provider result or settlement.

Planning, milestone packets and older work records describe history/specifications;
they are not mandatory development machinery. Record current work concisely in
work/records. Do not regenerate old cards or update frozen legacy denominators
to manufacture green checks. Preserve licensing terms, notices and dependency
locks. Release/distribution assurance remains separate from npm code checks.

Use normal Git branches and PRs. Local checks replace unavailable hosted Actions;
use `[skip ci]` and do not dispatch Actions. Respect real review/protection gates.
