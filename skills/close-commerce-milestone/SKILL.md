# close-commerce-milestone

Read the milestone G99 packet and original exit criteria. Check each in-scope component has actual accepted evidence; missing external observations remain blocked.

Integrate on one exact candidate, refresh against the current protected base including parallel accepted work and run the cumulative applicable native suite plus required connected/independent demonstrations. Do not combine green reports from incompatible commits.

Compare original requirement coverage, known limits, public claims, source financial/inventory records, no-AI and portable runtime/profile/platform behavior. Require independent security and regression reviews. An optional excluded feature stays explicitly unavailable; absent required v1 pilot evidence means beta/RC or a blocked v1 claim.

Record the trusted maintainer acceptance decision and obtain human approval for tagged/public releases. Do not publish, create external issues or spend funds merely because a milestone appears ready.
