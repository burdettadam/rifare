## Bounded outcome

The versioned owner-only API exports one merchant, accounts for all current
storage tables, and imports the same identity into an otherwise empty store in
one SQLite transaction. Business identifiers, monetary strings, receipts,
configuration bodies/digests, consent, evaluations, and privacy suppression are
retained. Source authentication and vault material are explicitly excluded;
opaque credential references require a compatible explicit local binding.

Import always installs the existing recovery quarantine. Imported approvals,
readiness, active work and configuration authority are paused; old operations
receive the existing replay fence. Identical imports are idempotent. A different
snapshot, foreign merchant, unknown schema, missing coverage, invalid relationship,
duplicate key, unsafe secret field or untrusted digest fails without partial data.
No original core schema, recovery guard, SecretVault or accepted test is changed.
