# M11-G04 — Replenishment preparation

State: implemented; root-owned native evidence and independent review pending.

Assigned by ADR-0040 from `b1e8be4a6a06ebe4289f95ba05630a13926e967a`, on
`goal/M11-procurement`, with one procurement author. Formal M07-G99/M08-G99
prerequisites and original goal acceptance remain blocked.

The actual planning service reads a stored currently reviewed forecast, an
anchored reconciled inventory position, current supplier terms and the stock
owner's authenticated receipt summary. It retains the forecast's original
temporal window, handles unit/minimum rounding, partial receipts and observed
cancellations, and blocks unknown inventory or supplier states. Its result is a
draft only. No second stock/receipt counter or purchasing authority is created.

Tests/known-answer fixture preceded implementation at `8e3bfba`; G04 has three
native cases within the eleven-case procurement file. The real arithmetic
function's incoming-stock term is deliberately removed in an isolated module;
the independently specified twenty minus ten minus six equals four assertion
detects the fault. Root alone captures the actual test result.

Implementation: `replenishment-planning.mts`, the G04 contract, shared procurement
core and privacy helper. Full methods, sources, temporal assumptions, pending
qualification and rollback are documented in `docs/PROCUREMENT.md`.

No author product executions, supplier contacts, payments, stock operations,
deployment, release or self-acceptance occurred.
