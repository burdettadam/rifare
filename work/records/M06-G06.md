## Implemented native contract and evidence

The frozen executable fixture uses the same conserved-value example at one tenth
of the illustrative scale above: 1,000 original plus 200 settled addition yields
1,200; a 300 residual leaves 900. A retail 1,400 with retained 200 discount makes
retail-price minting observably incorrect. The fixture was committed at b516470
before product implementation and remains unchanged.

Source transfer requires committed stock and native delivered replacement facts.
Original-unit claims, parent principal debit, child account/instruments and node
are one native transaction; core import has recoverable unknown state. Ingest
and financial boundaries bind descendants by native/resource identity even when
caller metadata is removed. Customer views omit ancestor payments. Cancellation,
workflow, export and retention include durable obligations. Unenrolled original
orders retain their previous behavior when a lineage source is attached.

were compared to omitted native routes (fixed411e4f3), and independently rounded
residual refunds could exceed a fee-adjusted instrument share (fixed0a8837a).

neither correction changes the independent fixture or a prior protected test.
The latter changes both core quote and independently recomputed native routing.
