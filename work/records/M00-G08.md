## Implemented result

The seven-module evidence controller is exported from fixed Git objects and reuses
the unchanged native regression and workflow implementations. Fresh capture uses a
predeclared external request, checks current source and configuration, runs native
suites, inventories all files and writes its external receipt last. Verification
reparses the native reports, validates artifacts/diagnostics/test IDs, source/build
identity, configuration, timestamps and retention, then rechecks trust inputs.
Review facts stay in a separately pinned external index and must cover the exact
manifest/receipt. No approval flags or candidate-local identities are imported.

The executed build is interpreted source, explicitly not a compiled application or
container. The schema and implementation reject unsupported compiled-build claims.
Private data/secret tripwires are conservative and cannot replace evidence review.
No automatic cleanup deletes evidence after success; a named custodian retains
decisions and required source/record identities before manual cleanup.
