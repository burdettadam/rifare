# M01-G03 — Opaque encrypted secret references

Authority: [ADR-0012](../../docs/decisions/0012-five-goal-local-implementation.md).
State: implemented for local diagnostic review; no production credential used.

Implementation: `packages/commerce/secrets.mts`, migration 003 and
`tests/development/commerce-secrets.test.mts`. A distinct random data key protects
each value with AES-256-GCM; a separately supplied wrapping key protects that data
key. Authenticated metadata binds tenant, store, opaque ref, provider and adapter.
Random nonces and full authentication tags are mandatory. Plaintext fallback does
not exist. Wrapping-key files must be regular, private, owned, unlinked files
outside the repository. Missing/wrong keys and altered metadata fail closed.

Only installed server adapters receive temporary plaintext buffers. UI/tool-facing
results carry opaque handles or a boolean synthetic-probe result. Adapter errors
and invalid result types cannot return the credential. Buffers owned by this
module are wiped after use; this is not a promise that JavaScript strings or a
trusted adapter's memory can be reliably erased. Adapter code is trusted native
code, not an untrusted-agent sandbox. No general secret-resolution HTTP endpoint
or provider/model call is implemented. Rewrapping retains the encrypted value and
updates only its wrapped data key; revoked references stop resolving.

CASE-M01-G03-01 maps to M01-G03-01; -02 to -02, -07 through -09 and -18;
-03 to -03 through -06, -10, -11 and -13 through -17. Nineteen tests additionally
cover rotation and in-flight revocation. Run:

```sh
node --experimental-strip-types --test tests/development/commerce-secrets.test.mts
```

The design was checked against Node's documented authenticated cipher interfaces
and OWASP cryptographic-storage/session guidance. No cryptographic algorithm was
invented. Local synthetic verification is not a security certification or hosted
KMS integration. Key backup/rotation authorization belongs to the operator; the
source archive and Git bundle intentionally contain no wrapping key.
