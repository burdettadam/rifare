# M01-G05 — Deterministic synthetic store

Authority: [ADR-0012](../../docs/decisions/0012-five-goal-local-implementation.md).
State: implemented for local diagnostic review; no provider operation is claimed.

Implementation: `packages/commerce/simulator.mts`, migration 005, the diagnostic
HTTP adapter in `apps/commerce-api/`, and `tools/dev-commerce.mts`. Supplemental
HTTP cases exercise the four earlier modules through their shared services. The
existing canonical resource-key formula is now a shared helper, not duplicated.

The versioned fixture contains two customers, two orders, catalog, shipment and
explicitly simulated payment data. Apparel and fragile profiles use the same
implementation with different known facts. Local fixture controls support reset,
read rejection, failure before acceptance and acceptance with a lost response.
Receipts preserve the last case's simulated state change for reconciliation;
retrying the same operation cannot apply it twice. Versions, known time and
optimistic conflicts are explicit. No transport accepts a live URL or credential.
The complete replay shape is validated before a reset or other effect.

CASE-M01-G05-01 maps to M01-G05-01; -02 to -02, -13 and -15; -03 to -03, -04,
-10, -11 and -14. Further cases cover durable receipts, conflicting requests,
invalid transitions, scoped cleanup and proof/session invalidation after reset.
M01-G05-CLI-01 starts two real linked-worktree servers, changes only the first
store's value, stops it while the second remains available, restarts the first,
and confirms persistence plus old-session revocation. It performs an offline
npm install using the unchanged zero-package lockfile.

```sh
node --experimental-strip-types --test tests/development/commerce-simulator.test.mts tests/development/commerce-cli.test.mts
node --experimental-strip-types tools/dev-commerce.mts
```

Ctrl-C stops only that command's instance and revokes the operator sessions it
issued. Private run files and the local proof-delivery outbox remain under the
ignored runtime path; no proof is returned by the challenge API. The outbox is a
development channel, not an email service. The static page is a diagnostic client,
not React. No full M01, MCP, live-platform or production qualification is claimed.

The same-batch maintainer review fixed rate-table growth after client throttling
and rejected absolute-form URLs with another authority; both have before/after
behavioral evidence. The integration record names the final full-suite and
mutation observations without fabricating independent reviewers.
