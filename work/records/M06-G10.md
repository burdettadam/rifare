## Intended behavior and independent expectations

Only confirmed replacement release plus current native unreturned original
units, valid consent/terms, a passed trial deadline and an unexpired mandate
permit capture. An expired mandate requires explicit fresh customer consent and
a separately approved reauthorization; it is never extended by a local timestamp.
Return and capture contend in one native SQLite transaction. If return wins,
capture excludes that unit. If capture wins, the later return records a bounded
compensation requirement and does not pretend the earlier capture vanished.

The fixture freezes original unit values at USD 10.00, 10.00 and 10.00. A partial
return leaves USD 20.00; all returned or canceled leaves zero. Reauthorization
cannot increase the original paid ceiling without matching new explicit source
consent, cannot change the original units, and cannot create a second capture
identity. Provider acceptance followed by timeout remains unknown locally until
the original operation lookup supplies its result, regardless of elapsed
provider idempotency windows or process restarts.

CASE-M06-G10-01/02/03 are permanent native Node cases. Additional boundaries
exercise consent revocation, expiry, partial returns, cancellation before and
after a reserved release, restart, source mismatch, cross-tenant denial, changed
approval authority, and real two-process return/capture contention. Deliberately
capturing the original full amount after partial receipt and allowing an expired
authorization must be killed by behavior assertions, with raw evidence retained.
