# M12-G03 local implementation handoff

State: ready for root integration and review; formal goal remains blocked.
Assigned by ADR-0041 at `7d2db376ebeed1c1d443ade322084f68f49661ca`, protected
product base `e36dbcd7cf392d04f21d082e834698bbc6a1ac79`.

AgencyReports calls actual SupportMetrics under each current opaque store scope.
It returns a hard allowlist of aggregate counts and denominators, sums before
calculating rates, retains incomplete follow-up, and excludes unauthorized stores
without exposing their identities. No report cache, customer record, credential
or financial observation pool is stored. Drilldown requires current store rights.

Tests-first commit `2cf57ce` defines CASE-M12-G03-01/02/03 with independently
declared 5-case combined and 3-case post-revocation cohorts. Real workflows,
customer confirmation and closure events populate metrics. A stale real aggregate
fault must fail the post-revocation denominator oracle. Author execution: zero.

Root captures native results, privacy integration, reviews and the local decision.
This does not qualify financial settlement, independent contribution, human
authorization or M07/M12 formal acceptance. AGENCY-OPERATIONS.md documents the
interfaces and limits.
