## Implemented boundary

`packages/commerce/operator-runbooks.mts` defines fixed commands, existing method
names, permissions and observed state transitions. It rejects blind retry,
hold/permission bypass, arbitrary shell commands and stale instructions.
Execution checks the actual method result at every step.

`tools/operator-drill.mts` is an executable fixed-name CLI. Its fixture driver in
`tools/operator-drill-fixtures.mts` runs ambiguous-refund, lost-webhook,
expired-token, stuck-hold, provider-outage, restore and agent-incident procedures
using existing commerce methods and separate SQLite fixture ledgers. The refund
drill also invokes actual `/v1/resolutions/operation` and
`/v1/resolutions/reconcile` HTTP routes. `docs/OPERATOR-RUNBOOKS.md` documents every
command, authority, source observation and fixture-administration step.

The expired-token drill expires an actual local idle session, bootstraps a fresh
authorized session and probes the existing encrypted credential slot. It does
not claim provider OAuth refresh qualification. Hold release waits for the
independent foreign hold owner. Restore retains quarantine, invalid copied
sessions, original operation IDs and blocked egress. Agent takeover retains the
same case and rejects the old lease and stale ownership generation.
