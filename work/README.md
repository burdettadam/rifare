# Work records

No product goal is assigned at bootstrap. The integration owner creates `records/<goal-id>.md` from `planning/templates/GOAL-WORK-RECORD.md` when a goal is assigned. Store concise source revisions, decisions, ownership, blockers and durable review links. Raw generated evidence belongs in ignored `evidence/`, not here.

Planning specifications stay proposed; this folder is the source-controlled live-progress surface. There is no separate task database. Unassigned tasks do not authorize unattended work.
