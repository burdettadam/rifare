# Qualification boundaries

`npm run check` supplies development feedback for the current Medusa/shared
code. Native backend verifiers supply scoped local database/HTTP observations.
Neither is connected-provider, settlement, physical durability, distribution,
commercial-transfer or production acceptance.

The owner retired the replaced SQLite code and its old qualification framework
under ADR-0093. Removed tests are retired, not passed. Historical test totals,
source/component inventories and artifacts do not qualify the simplified tree.
The interrupted native matrix remains failed/partial in private evidence.

Before release, resolve actual native findings and qualify the real provider
endpoint/enrolled caller, customer journey, deployment isolation/durability,
privacy/restore, dependency/license obligations and receiving-operator transfer.
Preserve actual review/authorization gates; no routine edit requires rehashing
all installed vendor files or repeating every fault/restore campaign.
