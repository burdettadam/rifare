# Rifare bootstrap

This checkpoint imports the bounded roadmap/goals as internal Rifare product targets, retains requirement/test IDs and their acceptance expectations, includes model-neutral workflow guidance, and supplies offline checks and contributor/work-record templates.

Vendor research archives and their source registries, old generated validation reports, recordings, screenshots, copied archives and machine-specific paths are not part of this repository. Capability targets are proposals, not claims about implemented software.

Git starts with a clean Rifare-only source tree. The initial commit uses the explicit `Rifare Bootstrap` identity, not a personal identity or a claimed signature. Set your own repository-local name/email before your first change.

The repository has no configured remote, hosted permission changes, production effects, paid services or product implementation. No product goal is accepted. The first packet is M00-G01. Licensing, support scope, actual client behavior and release controls remain decisions/qualification in their assigned goals.

Run `python3 tools/verify.py` after restore. Keep generated check output under ignored `evidence/`. A successful starter check is never product acceptance.
