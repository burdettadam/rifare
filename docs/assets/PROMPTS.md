# Rifare image prompts

These assets were generated with the built-in image-generation tool for the
portfolio presentation refresh. Prompts are retained for future art direction;
generative reruns are not expected to reproduce identical pixels. The checked-in
files are the selected artwork.

The logo was generated first. The hero and standalone mark used that logo as
their reference. The social artwork used the hero and logo. No external brand
assets, stock photography, or model weights were included.

## Horizontal logo

```text
Use case: logo-brand
Asset type: finished transparent logo lockup for Rifare, a merchant-owned commerce operations software project.
Create one distinctive, refined logo: an abstract geometric lowercase r formed from a continuous folded return path, with one purposeful turn suggesting an order finding its next destination. The symbol must be simple enough for a favicon and feel like designed software infrastructure, not a recycling logo, shopping cart, generic infinity, leaf, or circular arrow icon. Pair it with the exact lowercase wordmark "rifare" in a beautifully spaced confident contemporary grotesk sans serif, medium-to-bold weight, subtle custom shape details, highly legible.
Color: deep evergreen ink #163C32 for the wordmark and most of the symbol, with a restrained bright leaf/mint #C0EC88 accent on the return fold. Flat solid colors only.
Composition: single horizontal lockup, symbol left, wordmark right, generous clear space, approximately 3:1 landscape canvas. Keep mark and lettering compact and optically aligned. Transparent background, clean alpha edge.
Text verbatim: "rifare" (r i f a r e). No tagline, no extras, no multiple options, no mockup, no surface, no lighting, no gradients, no shadows, no border, no watermark. Final polished logo artwork, not a presentation sheet.
```

Place the provided Rifare logo near the upper-left, small but clear. Below it, set the headline in exceptionally clean, bold, deep evergreen grotesk typography, three deliberate lines:
```text
"Own what happens"
"after checkout."
Keep the first line on one line if space permits; both lines as a left-hand typographic block occupying roughly 55 percent of the composition. Beneath it, smaller readable text:
"Merchant-owned commerce operations."
And a lower-left small line:
"Returns / Exchanges / Support / Reverse logistics"
Right-hand half: one beautiful sculptural folded ribbon route in deep evergreen and bright leaf/mint, taking its folded shapes from the logo and forming an open architectural loop around a small simple warm cream parcel with subtle seam detail. A small apricot tile accents one turn. It is a conceptual brand illustration, not a workflow diagram or user interface.
Art direction: premium independent software brand, minimal editorial layout, lots of breathing room, crisp typography with strong hierarchy, sophisticated quiet color, visually memorable silhouette, no busy tech effects.
Use only the exact text quoted above plus the existing logo word "rifare". No additional words, no fake UI, no screenshots, no claims or numbers, no badges, no tiny decorative copy, no generic network nodes, no neon gradients, no photographic stock people, no extra logos, no watermark. Ensure all text stays within generous safe margins and is readable at README size.
```

## Standalone mark

Preserve exactly the silhouette, the negative-space opening, the deep evergreen body, and the light leaf/mint upper-right fold. Remove all wordmark letters. ## Upload export

`rifare-social.jpg` is a JPEG encoding of `rifare-social.png` at the same pixel
dimensions, exported at quality 94 with 4:4:4 chroma sampling. Its composition,
content, and framing are unchanged. Use the JPEG for GitHub's sub-1-MB social
preview requirement. Keep the PNG as the master.
