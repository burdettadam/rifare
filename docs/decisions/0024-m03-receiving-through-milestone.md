# ADR-0024 — Complete the local M03 lifecycle and assess the milestone

The owner assigns the remaining goals through the next milestone and retains the
prior delegation of local decisions, review, and nonrelease integration. This
checkpoint precedes implementation from `79bd07e`. One writer owns
`goal/M03-completion` for M03-G16 through M03-G21 and the M03-G99 assessment.

DELEGATED-LOCAL-15 authorizes a bounded diagnostic implementation of warehouse
receiving, explicit item disposition, cancellation/expiry, portable return and
exchange skills, and reconciliation of independently observed source changes.
Use the existing scope, policy, preview/approval, source identity, privacy,
execution-stop and operation-reconciliation controls. Keep actual receipt,
inspection, inventory disposition, financial settlement and shipment distinct.
Same-assistant maintainer review is explicit, not independent reviewer sessions.

Owned changes: additive commerce modules, migration 017, synthetic source adapter,
canonical gateway/HTTP/privacy hooks, source-traceable lifecycle status, two
portable skill packages, independent client, tests, bounded demo and documentation.
Preserve all earlier executable tests, IDs, contracts, benchmarks and dependencies.
No new scheduler, framework, provider dependency, release, remote, paid effect,
real inventory/financial operation or customer contact is authorized.

Connected platform, PostgreSQL/React, served-browser and pilot evidence cannot be
invented. M03-G99 must report these unmet exit criteria and must not mark the full
milestone accepted solely because the diagnostic lifecycle passes. Local source
integration is permitted after actual cumulative tests and documented review.
