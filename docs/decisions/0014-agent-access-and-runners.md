# ADR-0014 — Agent access, manual reads and replaceable runners

The owner assigned M01-G11 through M01-G15 and retains delegated decision,
review and local-merge authority. Begin from main 9e93d46; one writer owns
branch goal/agent-access-batch. This checkpoint precedes implementation.

Scope: task-bound MCP read tools, a no-model manual status screen, provider-neutral
read assistance with two server-installed wire adapters, and a separately written
Python orchestration example. Reuse canonical read handlers, profiles, skill
content, portable tasks and the encrypted vault. Never forward an incoming bearer
token to a provider. No commerce writes, email, deployments or paid calls.

Continue the prior ordering exception: diagnostic SQLite work may be integrated
without pretending PostgreSQL/React or live-provider qualification passed. The
wire adapters will be exercised with synthetic responses. Installed credentials,
live model access and paid egress are not available or inferred. Outbound transports
remain disabled absent an explicit server-local endpoint/model/credential approval.
A custom deterministic external client proves orchestration separation, not a
second independently authored AI product or measured real-model answer quality.

DELEGATED-LOCAL-05 permits documented maintainer authority/security and regression
review for this nonrelease merge. No independent reviewer identity is invented.
Preserve all retained executable assertions, specification contracts and benchmark
thresholds. Refresh external pins only after reviewing exact changes; allow additive
registrations and explicit source-inventory/file-count updates. Do not add an agent
framework, another scheduler, mandatory provider or runtime dependency.

Allowed write paths: new packages/agent modules, additive commerce migration if
needed, MCP/manual read server integration, standalone external client, new tests,
associated work records and documentation, additive inventory/registry entries.
Existing application behavior and previous source paths remain supported.
