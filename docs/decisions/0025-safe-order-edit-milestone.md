# ADR-0025 — Safe order editing through the M04 assessment

The owner assigns the next milestone from `fe2c9ce` and retains delegated
implementation, review and local merge authority. This checkpoint precedes code.
One writer owns `goal/M04-safe-order-edit`. DELEGATED-LOCAL-16 permits the bounded
M04-G01 through M04-G11 diagnostic implementation and M04-G99 assessment, with
same-assistant maintainer review disclosed rather than invented independent reviews.
M00–M03 connected/target qualification remains open and is not waived.

Use the existing gateway, exact approvals, case pins, current permissions, stops,
privacy and recovery guards. Add order edit, independent fulfillment holds,
version-bound payment/refund obligations and explicit recovery through a separately
persisted synthetic store/warehouse source. A tag alone is not hold proof. No
live carrier/store/financial transport, payment, message, external account, new
package dependency, release tag, public remote or M05 work is authorized.

Owned paths are additive order-edit modules/source/migration/skill/test/demo/HTTP
and manual view, targeted gateway/stops/privacy integration, inventory and test
registrations, work records and milestone assessment. Preserve prior source paths,
all existing executable test bytes and mappings, dependency inputs, original goals
and benchmarks. A passing synthetic probe is not live warehouse qualification.
