# Decisions

No product decision is approved by this bootstrap. Create reviewed records from `templates/ADR.md`. Record the actual decision-maker, date, source/context, affected IDs and consequences. Do not replace earlier accepted controls retroactively.


## Browser roadmap adoption

[ADR-0044](0044-browser-roadmap-adoption.md) records the owner's current
planning-only instruction, protected M14 source, exact M23–M25 additions,
independent reviews and the narrow planning metadata corrections. Actual local
integration is recorded separately after validation; no product goal or release
is accepted by generating the new packets.
