# ADR-0008 — Retained regression obligations and an external controller

Status: delegated preparatory implementation decision, recorded before source changes.

The owner requested the next goal and previously delegated project decisions.
M00-G06 at `4a88504` supplies diagnostic tests but remains unaccepted. Authorize
bounded M00-G07 work on that branch; do not alter prerequisite acceptance, the
accepted-goal ledger, main, or the existing limited review exception. M00-G07
cannot qualify the target stack or a product release.

Retain the existing 408 runnable test identities, distinguishing the 289 accepted
bootstrap checks from 119 unaccepted diagnostic checks. None of the 676 commerce
specifications become runnable or accepted by registration. Pin the initial
registration and fixture/source obligations before implementing the controller.

Use the existing inventory checker, native unittest/Node/browser reports, and
ordinary Git. Add a read-only gate and a minimal unittest report adapter, not a
scheduler or agent framework. Export fixed source and baseline bytes to a separate
controller directory. Caller-supplied commit/content pins must come from a trusted
maintainer/control workflow, not candidate configuration. Never execute a
candidate-authored approval or let a candidate regenerate the retained baseline.
Local same-user files are not hosted branch protection or an OS sandbox.

Protect existing test/oracle bytes and policy definitions. Permit new tests and
files without shrinking old obligations. The inventory-count fixture may change
only to equal the exact committed source membership, with all previous source
paths retained and all other fixture fields unchanged. Its explanation may
reflect enumerated additions. This narrowly defined structural extension is not
permission to change a behavioral oracle, test threshold, or acceptance condition.
Any other protected change blocks pending independent review and a separately
retained new baseline; no approve/ignore switch is authorized.

Keep main and previous branches intact. Run complete available local checks,
meaningful mutants, clean restore and external-controller demonstrations. No
network service, new package dependency, production operation, publication,
release tag or M00-G08 work is authorized. Missing independent reviews and
unfinished target-stack prerequisites remain explicit blockers.
