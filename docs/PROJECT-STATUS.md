# Project status

Rifare's active application is Medusa/PostgreSQL with native cart, identity and
original-operation guards. The owner has authorized retiring the replaced SQLite
application rather than maintaining two implementations until complete parity.

The simplification removes legacy runtime and bespoke qualification machinery;
it does not accept the paused native matrix or resolve its failed process check.
Earlier evidence remains bound to its original source and artifacts. Rebuilt
shared adapters require their own relevant checks.

Connected provider/caller evidence, complete customer-facing migration,
deployment/durability, commercial transfer and production acceptance remain open.
See [remaining work](ROADMAP.md) and [development](DEVELOPMENT.md).
