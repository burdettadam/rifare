# M17-G02 — Authorize exact media versions for bounded model processing

**Milestone:** M17 · **Type:** worker_goal · **Lane:** decision_models_and_skills · **Risk:** critical

**State:** not started · **Owner:** unassigned · **Execution:** local_then_separate_qualification

> Planning specification only. No application test, provider operation or feature completion is claimed.

## Outcome

Permit model access only to the authorized case's approved immutable image version through a controlled server path.

## Dependencies

[M17-G01](../M17/M17-G01.md); [M13-G99](../M13/M13-G99.md); [M14-G99](../M14/M14-G99.md)

Dependencies must be **accepted**, not merely assigned or implemented. Inspect current accepted evidence before starting.

## Bounded ownership

- Reuse case permissions, opaque media references, expiry/revocation checks, and server-side credential handling to mediate model reads.
- Bind processing access to tenant, case, attachment hash/version, purpose, approved provider/modality, and current work ownership.
- Decode/process in a bounded environment, record any resizing or metadata removal, and prevent arbitrary URL fetching or model-directed attachment selection.
- Keep provider-specific embedding/size/context behavior inside the media adapter capability contract.

Additive specification from the separately retained roadmap. Concrete assignment and allowed paths require a prior maintainer record; only M13 is assigned by ADR-0042.
