## Evidence to submit

Proposed bundle: `evidence/M00-G08/<candidate-sha>/`

- manifest.json: candidate/base SHA, source-tree/build digests, config/skill/policy/model/adapter pins, environment, fixture hashes and actual timestamps.
- tests/native-report.* and tests/results.json: exact commands/exit codes, discovered and executed stable case IDs, totals and native report hashes; zero-test/skip/todo is not pass.
- red-green.md: observed behavioral red failure or valid targeted mutant failure, repaired-candidate pass, and the exact code/config change that caused each outcome.
- demo.md plus sanitized API trace or UI recording: demonstrate the named outcome on this candidate; screenshots alone do not establish money or stock correctness.
- regression-review.md: compare accepted capability/test baseline, changed/deleted tests and oracle files, compatibility, migrations and old journeys; independent reviewer decision.
- security-review.md: independent authority/tenant/secret/side-effect review proportional to risk; no self-approval for critical changes.
- handoff.md: implementation paths, actual commands, remaining limits, rollback/recovery, deployment/support implications and next unblocked goals.
- decision.json: trusted integration owner/maintainer acceptance is separate from author evidence; public/tagged release requires human authorization.
- Evidence schema; tampering tests; trusted-review boundary and lifecycle/cleanup instructions.

## Completion and regression protection

The author reports **ready for review**, never self-accepts. A trusted integration owner/maintainer accepts after independent regression/security review. A tagged/public release requires human authorization.

**Protected feature:** `FEATURE-M00-G08`

**Test obligations:** `CASE-M00-G08-01`, `CASE-M00-G08-02`, `CASE-M00-G08-03`

After trusted goal acceptance, add executable test/capability contracts to the protected accepted baseline. Candidate changes cannot silently shrink that baseline.

Run own tests plus all accepted tests impacted by this change, all introduced cross-cutting invariants, and the deterministic regression suite. Milestone/release candidate runs the full applicable accepted suite and required connected qualification.

Any removed/changed protected test, fixture, expectation, selector, qualification threshold or capability needs independent regression review. Preserve a behavioral oracle and demonstrate the targeted fault is detected.

**Introduced cross-cutting invariants to retain:** INV-12, INV-13

A skipped test, a changed denominator, a mutable screenshot baseline or a self-authored pass report is not regression evidence. Changes to protected expectations need independent review; current integrated-candidate results supersede old branch results.
