# M15 — Sender-bound remote agent access

Add one standards-based remote authorization profile to the existing task and worker boundaries, so possession of a copied token alone cannot read case data or prepare a proposal. Keep tenant, customer, task, policy, approval, lease and stop decisions in the existing server authority.

## Preserved qualification obligations

Use one synthetic return case: an independent sender-bound client reads facts and prepares a proposal, a copied-token client fails, a two-process proof replay admits at most one request, revocation fences continuation, and the existing operator flow remains available.

- The actual remote profile cannot be enabled without verified sender binding, current task authority and shared replay enforcement. A portal is optional and cannot weaken direct-origin checks.
