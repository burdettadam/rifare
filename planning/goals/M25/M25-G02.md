## Bounded ownership

- Select one actual browser runtime/model path and verify support for its vision encoder/projector, processor, decoder representation interface and trained Clef joint head. Kevala's current Flash path is text-only; a Gemma image companion cannot be assumed compatible with Clef.
- Pin companion weights, preprocessing and tokenizer/position conventions, runtime/glue/WASM/shader build, text pack, quantization and compatibility manifest. Compare the intended image request with the pinned upstream multimodal reference.
- Add the narrow image-to-decision bridge only where needed: decode/process authorized pixels, obtain correctly positioned image representations, combine bounded text/questions and invoke the complete joint head. Generic chat image handling or a loaded mmproj file alone does not qualify createSystemOne.
- The Wllama route is optional. If chosen, verify its required joint and image-file transport/build path directly; M24's entire compact-backend milestone is not a hard prerequisite. If no suitable bridge is available, record the blocker and keep image controls disabled.
