## Bounded ownership

- Declare browser-local inference, ordinary Rifare evidence retrieval/observation submission, model artifact downloads and any separately selected server provider as distinct data destinations. A local model load failure is not permission to upload case text elsewhere.
- Minimize client state, prohibit case evidence in artifact URLs and telemetry, and disable persistent evidence/prefix caching by default. If an approved cache is later retained, scope it to tenant, actor/session, purpose and exact evidence/configuration revisions with the existing erasure owner.
- Wire abort, deadline, ownership change, evidence correction, logout, tenant switch and page/worker termination into cancellation and late-result fencing. Use current server checks on any resumed or offline proposal; client cancellation is not proof that the GPU stopped instantly.
- Reuse privacy export/erasure/restore suppression for server client-observation records, and provide client cache/worker disposal for the stores Rifare controls. Keep public weight caches distinct from customer-derived data; do not claim secure erasure of malicious-client memory, screenshots or exported copies.
