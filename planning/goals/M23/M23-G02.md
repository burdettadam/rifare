## Outcome

## Bounded ownership

- Integrate a dedicated browser worker and explicit load/unload states using the selected Clef-capable runtime. Keep model selection separate from downloading; expose expected bytes, destination, progress and cancellation before a large transfer.
- Accept only operator-approved manifest identities and artifact origins. Verify the selected runtime and pack artifacts, including incomplete downloads, before declaring the model usable; do not run arbitrary caller-provided scripts or model URLs.
- Check the browser execution features, actual GPU adapter/limits, storage quota and a bounded allocation/warmup result. Account separately for downloaded bytes, coordinator memory, GPU weights and working buffers; cache presence is not evidence of a resident or usable model.
- Keep model-pack cache separate from case evidence and inference state. Bound download concurrency and retries, handle quota eviction and device loss, and avoid claiming browser CPU fallback can load a pack beyond its allocation limit.
