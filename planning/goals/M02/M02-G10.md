# M02-G10 — Route every proposed write through one action gateway

**Milestone:** M02 · **Type:** worker_goal · **Lane:** api · **Risk:** critical

**State:** not started · **Owner:** unassigned · **Execution:** local

> Planning specification only. No application test, provider operation or feature completion is claimed.

## Outcome

Implement typed action dispatch enforcing tenant, verified customer, capability, policy and current resource state for UI/REST/MCP/automation callers. Initially execute reversible synthetic actions only.
