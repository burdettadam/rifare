# Historical requirements and specifications

The active development path is [Medusa](../docs/ARCHITECTURE.md), using the
[normal npm workflow](../docs/DEVELOPMENT.md). This directory is reference material,
not an active task scheduler, rendered queue or qualification result.

The duplicate goal/milestone Markdown pages and HTML/Markdown catalogues were
retired after the SQLite application. Their canonical content remains here:

- `goals.json`: detailed goals, unfinished integrations, scope and criteria.
- `milestones.json`: milestone definitions and exit criteria.
- `test-specifications.json`, `requirement-coverage.json` and `capability-targets.json`:
  historical product requirements and their mappings.
- `reference/`: original requirements and accepted source criteria.
- Other policy, inventory and registration JSON: historical decisions/input records,
  not current native or release acceptance.

No requirement is accepted by removing its rendered copy. Older work records may
reference retired paths; use their recorded Git revisions to inspect those files.
Do not recreate the old rendering/check framework for routine development. Current
remaining work is summarized in [the roadmap](../docs/ROADMAP.md).
